# Lesson Blueprints

## Purpose

Lesson blueprints make every video feel consistent without forcing every drill into the same duration or edit.

The same teaching structure should support:

- course lessons,
- drill breakdowns,
- short social cutdowns,
- square feed previews,
- marketing clips.

## Course Lesson Blueprint

Use for `16:9` course and website video.

| Segment               | Purpose                          | Typical content                                       |
| --------------------- | -------------------------------- | ----------------------------------------------------- |
| intro                 | orient the viewer                | lesson title, technique objective, brief brand signal |
| learning objective    | explain what to look for         | one clear outcome                                     |
| normal-speed demo     | show real motion first           | clean swim clip with minimal overlays                 |
| slow-motion breakdown | reveal timing and body position  | one cue at a time                                     |
| freeze frame          | isolate key position             | label + one or two guides                             |
| common mistake        | show what goes wrong             | mistake label, non-color-only indicator               |
| correction            | show correct movement            | fix label, clean comparison                           |
| drill                 | give a practice path             | drill name, setup, cue                                |
| practice cue          | leave the swimmer with one focus | short phrase                                          |
| summary               | reinforce the takeaway           | one to three bullets or spoken summary                |

## Social Vertical Blueprint

Use for `9:16`.

Keep the clip focused on one teaching idea.

| Segment    | Purpose               | Rule                                                    |
| ---------- | --------------------- | ------------------------------------------------------- |
| hook       | state the cue quickly | first `1-2s` should show the technique point or outcome |
| demo       | show motion           | minimal overlay, strong crop                            |
| correction | show what to change   | one label or comparison                                 |
| drill cue  | give the action       | short and memorable                                     |
| close      | brand or next step    | brief, no long outro                                    |

## Square Social Blueprint

Use for `1:1`.

Best for:

- before/after,
- one mistake and one fix,
- one practice cue,
- a short drill preview.

Avoid dense lesson structure. The square format should not try to carry a full course lesson.

## Marketing Clip Blueprint

Use only when the clip is meant to create interest, not teach the full lesson.

- Start with the result or visible problem.
- Use one coaching cue.
- Show enough brand context to feel FreeSwimming.
- End with one clear next action.
- Do not oversell or make unverified performance claims.

## Educational Rules

- Show normal speed before slow motion when possible.
- Do not start with abstract explanation if the movement can be shown.
- A freeze frame should clarify a position, not interrupt flow randomly.
- A drill should connect directly to the mistake or focus cue.
- The final practice cue should be actionable in the pool.

## Pacing Rules

- Course video can use more context and comparisons.
- Social video should use one idea and one action.
- If a lesson needs multiple technique ideas, split it into multiple cutdowns instead of crowding one clip.

## Reuse Rule

Each produced lesson should be planned so its course master can generate:

- one full `16:9` course export,
- at least one `9:16` social cutdown,
- optionally one `1:1` feed/ad export.

This does not mean every lesson must publish all formats. It means filming and overlay design should keep the option open.
