# UX Principles

## Core Principles

- Mobile first: design and test for touch and small screens first.
- Calm clarity: one primary action per view, clean visual hierarchy.
- Fast orientation: users should always know where they are and what to do next.

## Interaction Standards

- Buttons and links must preserve keyboard semantics.
- Escape should close dismissible overlays/drawers.
- Focus should move predictably and return to trigger after close.

## Forms

- Labels are always explicit and programmatically associated.
- Error messages are clear, short, and connected via ARIA.
- Avoid auto-focus patterns that force mobile keyboard on page load.

## Content Standards

- Use plain language and short task-oriented copy.
- Keep examples concrete and tied to user goals.
- Keep key outcomes visible (what happens after submit, expected response time).
