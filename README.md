# freeswimming

Next.js app for freeswimming.org.

## Local setup

1. Install dependencies:

```bash
npm install
```

2. Create local env file:

```bash
cp .env.example .env.local
```

3. Start dev server:

```bash
npm run dev
```

## Key env vars

- `RESEND_API_KEY`: API key for Resend email delivery.
- `CONTACT_TO_EMAIL`: recipient mailbox for contact form submissions.
- `CONTACT_FROM_EMAIL`: sender identity used in outbound email.
- `CONTACT_ALLOWED_ORIGINS`: comma-separated allowlist for POST `/api/contact`.
- `UPSTASH_REDIS_REST_URL`: optional Upstash Redis REST URL for distributed rate limiting.
- `UPSTASH_REDIS_REST_TOKEN`: optional Upstash Redis REST token.
- `NEXT_PUBLIC_FS_AUTOGEN_LESSONS`: `1`/`0` toggle for local autogenerated course lessons.
- `NEXT_PUBLIC_FS_AUTOGEN_COUNT_M1`: local lesson count target for module 1 autogen.

If Upstash vars are missing, the contact API falls back to in-memory rate limiting.
